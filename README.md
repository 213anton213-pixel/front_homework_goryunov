собери сумму — дз №2
небольшая игра на javascript без фреймворков. надо собрать заданную сумму ровно из трёх разных целых чисел от 1 до 9. числа добавляются через форму и удаляются кнопкой ×. цель выбирается случайно от 6 до 24: каждую можно собрать.

запуск
нужна актуальная lts-версия node.js 26 (проект проверен на 26.13.0, npm 11.20.0). версия указана в файле .nvmrc и в package.json. скачать node.js можно с официального сайта nodejs.org в разделе download.

после клонирования открой терминал в каталоге проекта и выполни npm ci, затем npm run dev. открой локальный адрес, который напечатает vite. для проверки собранной игры выполни npm run build, а затем npm run preview. учти, что preview использует готовый каталог dist, поэтому сначала нужна сборка.

проверки
есть четыре команды: npm test, npm run lint, npm run format и npm run format:check.

test — это встроенный тестовый модуль node.js, работает без браузера. он проверяет допустимый ввод, уникальность чисел, лимит в три числа, победу, отмену хода и отсутствие изменений исходного состояния. lint — это oxlint, как в примере проекта преподавателя. format — это prettier, он приводит файлы к единому стилю, а format:check проверяет стиль без изменений.

устройство проекта
index.html содержит постоянную разметку страницы и формы. src/game.js — это чистые функции с правилами игры. src/main.js отвечает за состояние, события и отдельную функцию render(). src/storage.js занимается загрузкой, проверкой и сохранением партии. src/style.css отвечает за оформление и адаптацию к узкому экрану. test/game.test.js содержит проверки правил в node.js.

обработчики событий меняют состояние, а dom обновляет render(). поле ввода не пересоздаётся. при вводе сохраняется черновик, а при удалении числа текст в поле остаётся. после успешного добавления поле очищается для следующего числа.

zod — единственная игровая npm-зависимость. она проверяет структуру сохранения, диапазоны, отсутствие повторов и размер списка. без неё проверка данных сохранения не работает. отрисовка, ввод и правила написаны самостоятельно.

цель, список чисел и незавершённый ввод сохраняются в localstorage под ключом sum-game. после перезагрузки партия продолжается, включая состояние победы. повреждённый json или неверные данные заменяются новой партией. если хранилище недоступно, игра работает без сохранения. в игре нет движения и анимационного цикла, поэтому частота экрана и возврат на вкладку не влияют на правила.

ручная проверка
добавь число через enter, затем ещё одно кнопкой. удали одно из списка. начни вводить следующее число и удали уже добавленное: текст в поле должен остаться. перезагрузи страницу: цель, список и черновик должны восстановиться. в инструментах разработчика измени значение sum-game в local storage на {broken и перезагрузи страницу. должна открыться новая партия без ошибок в консоли. повтори с корректным json, но неверной структурой, например target 15 и numbers 2, 2 с пустым draft. набери цель тремя разными числами: появится сообщение о победе. кнопка × позволяет отменить ход, а «новая игра» начинает новую партию.

node_modules и dist исключены через .gitignore. package-lock.json хранится в репозитории, чтобы npm ci устанавливал зафиксированные версии.
