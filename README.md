собери сумму — дз №3
игра из дз №2, перенесённая на react и typescript. надо собрать заданную сумму ровно из трёх разных целых чисел от 1 до 9. числа добавляются через форму и удаляются кнопкой ×. цель выбирается случайно от 6 до 24: каждую можно собрать. правила и оформление с times new roman сохранены.

запуск
нужна актуальная lts-версия node.js 26 (проект проверен на 26.13.1, npm 11.20.0). версия указана в файле .nvmrc и в package.json. скачать node.js можно с официального сайта nodejs.org в разделе download.

после клонирования открой терминал в каталоге проекта и выполни npm ci, затем npm run dev. открой локальный адрес, который напечатает vite. для проверки собранной игры выполни npm run build, а затем npm run preview. preview использует готовый каталог dist, поэтому сначала нужна сборка. в powershell при блокировке npm.ps1 используй npm.cmd вместо npm.

проверки
команды из дз №2 сохранены: npm test, npm run lint, npm run format и npm run format:check. npm run build сначала запускает строгую проверку типов через tsc --noEmit и собирает игру только при отсутствии ошибок.

test — встроенный тестовый модуль node.js, работает без браузера. семь прежних тестов правил перенесены на typescript. дополнительно проверяются обновление состояния, сохранение черновика, отмена победного хода, новая партия и отсутствие изменений исходных данных. тесты сохранения проверяют совместимость с дз №2, повреждённый json, неверные данные и недоступное хранилище. lint — oxlint. format — prettier, он приводит файлы к единому стилю, а format:check проверяет стиль без изменений.

устройство проекта
index.html содержит корневой элемент страницы. src/main.tsx подключает react. src/App.tsx связывает состояние и компоненты. src/components/ScoreBoard.tsx показывает цель, сумму и количество чисел. NumberList.tsx отвечает за список и кнопки удаления. NumberForm.tsx содержит поле ввода и добавление числа. src/game.ts содержит чистые функции с прежними правилами игры. src/state.ts описывает состояние партии, действия и их обработку. src/storage.ts занимается загрузкой, проверкой и сохранением партии. src/style.css содержит прежнее оформление.

test/game.test.ts содержит прежние тесты правил. test/state.test.ts проверяет действия, а test/storage.test.ts — сохранение. в tsconfig.json включён strict. типами описаны данные игры, действия и свойства компонентов. код приложения и тесты проверяются при сборке.

у игры одно общее состояние в App. обработчики отправляют действия, а react обновляет интерфейс. компоненты объявлены отдельно, а ключи элементов списка — сами уникальные числа. поле ввода не пересоздаётся при каждом обновлении. при вводе сохраняется черновик, при удалении числа текст в поле остаётся. после успешного добавления поле очищается для следующего числа.

zod проверяет структуру сохранения, диапазоны, отсутствие повторов и размер списка. без неё проверка данных сохранения не работает. правила и обработка действий написаны самостоятельно, отображение сделано компонентами react.

цель, список чисел и незавершённый ввод сохраняются в localstorage под прежним ключом sum-game. сохранения из дз №2 совместимы, если игра открыта на том же адресе. после перезагрузки партия продолжается, включая состояние победы. повреждённый json или неверные данные заменяются новой партией. если хранилище недоступно, игра работает без сохранения. движения и анимационного цикла нет, поэтому частота экрана и возврат на вкладку не влияют на правила.

ручная проверка
добавь число через enter, затем ещё одно кнопкой. удали одно из списка. начни вводить следующее число и удали уже добавленное: текст в поле должен остаться. введи несколько символов подряд: поле должно сохранять фокус и введённый текст при обновлениях. перезагрузи страницу: цель, список и черновик должны восстановиться. в инструментах разработчика измени значение sum-game в local storage на {broken и перезагрузи страницу. должна открыться новая партия без ошибок в консоли. повтори с корректным json, но неверной структурой, например target 15 и numbers 2, 2 с пустым draft. набери цель тремя разными числами: появится сообщение о победе. кнопка × позволяет отменить ход, а «новая игра» начинает новую партию.

node_modules и dist исключены через .gitignore. package-lock.json хранится в репозитории, чтобы npm ci устанавливал зафиксированные версии.
